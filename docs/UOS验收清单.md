# UOS 桌面验收清单

目标环境为统信 UOS 专业版 1070、飞腾 FT-2000 ARM64。当前 Windows 检查和 Linux 构建配置不能替代本清单中的实机结果。

## 环境记录

在终端记录以下信息，并通过 `reader.log` 核对应用实际运行的架构：

```bash
cat /etc/os-release
uname -m
getconf GNU_LIBC_VERSION
printf '%s\n' "$XDG_SESSION_TYPE"
```

另外记录完整 CPU 型号、内存容量、显卡、分辨率、桌面缩放比例，以及合成效果是否启用。不收集用户书籍内容。

## 安装与普通阅读

- [ ] 安装 ARM64 DEB，或解压 ARM64 tar.gz 后运行可执行文件。
- [ ] 缺少依赖时记录终端错误，不直接替换系统 glibc，也不关闭 Chromium 沙箱。
- [ ] 导入 UTF-8、GB18030、UTF-16 TXT，检查中文、标点、目录和末尾章节。
- [ ] 导入至少五本实际使用的无 DRM EPUB，检查目录、图片、翻页和重启位置。
- [ ] 调整字号、行距、字体、主题，重启后保留设置。
- [ ] 大 TXT 导入时可以正常移动窗口，阅读时不全书重新排版。
- [ ] 移除条目后用户原始文件仍在，书架变化重启后保留。

## 悬浮与恢复

- [ ] 普通窗口与悬浮模式来回切换，内容位置合理。
- [ ] 0.1.4 默认背景模式：背景为 0% 时能透出 Word 等底层窗口，文字为 100% 时仍清晰；TXT、EPUB 均检查，正文可独立调淡。
- [ ] 背景模式下 X11 整窗透明度保持 100%，避免正文被旧整窗设置再次淡化；透明区域经过鼠标不闪烁，真正移出后隐藏。
- [ ] 整窗透明度统一生效，24% 时标题栏、按钮、正文、背景和 EPUB 区域一起变淡，没有不透明残块、黑底或残影。
- [ ] X11 整窗模式确认 1% 时系统圆角边框和阴影同步淡化；移出隐藏后外框完全消失，移回后恢复原透明度。
- [ ] 1% 低透明度时仍可用 Ctrl+Alt+0、快捷滑块或托盘菜单恢复不透明。
- [ ] 拖动、调整大小、跨屏及桌面缩放后内容正常。
- [ ] 悬浮右上角自动隐藏开关位于整窗透明度左边；移出后整窗为 0% 且无提示条，移回原窗口区域恢复原透明度，不抢走其他应用输入焦点。
- [ ] 全透明时仍能检测原窗口区域，核验当前 X11/Wayland 会话的光标位置能力；关闭自动隐藏后移出保持原透明度。
- [ ] EPUB 内部框架与阅读按钮之间移动时不误隐藏。
- [ ] 打开设置和文件选择对话框时不会自动隐藏。
- [ ] Ctrl+Shift+Space 隐藏和恢复，托盘入口可用。
- [ ] 全局快捷键被占用或托盘不可用时，可以通过现有窗口退出。
- [ ] 老板键隐藏后，不会因原阅读区域经过鼠标而意外恢复。

## 记录方式

分别注明 X11 和 Wayland 的结果；未测试的会话保持“待验证”。记录空闲 CPU、阅读时内存、长时间挂起后的恢复行为，以及显卡或合成器相关异常。不要用普通 ARM 云主机的测试代替飞腾显卡和 DDE 窗口行为验收。
